# Skala — Agency Coaching Website

Statische Website für ein Coaching-Angebot, das Gründer beim Aufbau und der
Skalierung ihrer Social Media Agentur begleitet.

## Seiten

| Datei | Inhalt |
|---|---|
| `index.html` | Startseite: Hero, Leistungsüberblick, Zahlen, Prozess, Stimmen, Für-wen, FAQ, CTA |
| `leistungen.html` | Programm: 6 Module im Detail + Formate der Begleitung |
| `projekte.html` | Ergebnisse: 3 Case Studies + Teilnehmerstimmen |
| `überuns.html` | Über uns: Story, Prinzipien, Team, Zahlen |
| `impressum.html` `datenschutz.html` `agb.html` `haftungsausschluss.html` | Rechtstexte |

## Technik

Reine HTML-Dateien, kein Build-Schritt. Tailwind kommt per CDN, Fonts von Google Fonts.
Einfach `index.html` im Browser öffnen oder den Ordner auf einen Static Host legen.

## Noch anzupassen

- **Domain & E-Mail:** alle CTAs zeigen weiterhin auf `office@capitalcouncilmarketing.com`
- **Social-Links** im Footer sind Platzhalter (`href="#"`)
- **Zahlen und Case Studies** sind Platzhalter und sollten durch echte Werte ersetzt werden
- **Impressum:** die Firmendaten (28 Capital Council LLC) wurden unverändert übernommen
